## Reproduced software defects

| Defect | Consequence | Fix and verification |
|---|---|---|
| `exige_v2()` checked only whether `DMAGA_BIG` was set. | An explicit value could select archived data, raw evidence or an alias and authorize overwriting it. | Resolve paths and reject protected roots, descendants and ancestors. Regression cases cover direct paths, descendants, parents, aliases and a separate output directory. |
| `run_derive.sh` lacked `pipefail`. | A failed producer behind `head` or `tail` could be followed by a successful `DERIVE_OK`. | Enable `pipefail`; replace early-closing `head` filters with consuming `sed` filters. Three failure simulations verify exit codes and that later stages do not run. |
| Accounting continued with missing SOL/USD prices. | Stablecoin consideration could be valued at zero; incomplete USD totals could be published. | Reject missing, zero, negative and non-finite prices before publication. Tests preserve an existing output on failure and verify a valid stablecoin conversion. |
| Temporary table `x` was conditional but used unconditionally. | Missing transfer input caused a late, misleading database error. | Check required accounting inputs first. An empty, correctly typed transfer file remains valid; a missing file is not treated as no transfers. |
| `wallets.parquet` was written in place. | Interrupted output could replace a previously valid result with a partial file. | Write `wallets.tmp.parquet`, then replace the result after the write succeeds. No archived result was regenerated in this review. |
| All X HTTP errors became permanently cached unavailable posts. | A 429, 403 or 503 could be mistaken for lasting source unavailability. | Only 404/410 are recorded as unavailable at that source; other HTTP errors fail the batch. Store both source statuses and permit retries of ambiguous historical rows. |

A real replay may now stop at price gaps that were previously hidden. Complete the input data in a separate derivation; do not restore a zero-price fallback.

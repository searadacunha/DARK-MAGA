## 1. Décodeur SPL qui préserve le mint

`dmaga/spl.py` décode chaque instruction System et SPL, internes comprises. Un compte de jetons est rapporté à son propriétaire et à son mint, dans l'ordre :
1. par les soldes pre/post de la transaction ;
2. par les `initializeAccount*` de la même transaction, pour un compte créé puis fermé dans la transaction.

Règles :
- les montants restent des entiers bruts ;
- une transaction échouée ne produit aucun mouvement ;
- un compte non résolu garde `owner_known=False`.

Fixtures réelles (`tests/fixtures/spl/`, `tests/test_spl_decoder.py`) :

| Cas | Résultat attendu |
|---|---|
| `Transfer` sans le compte du mint (6t2dz4jm → AtZj) | mint et propriétaires retrouvés |
| `TransferChecked` (7GVC → 9Sxm) | même décodage |
| compte WSOL créé et fermé dans la transaction (vente de 9Sxm) | propriétaire retrouvé par l'initialisation |
| ATA WSOL fermée (clôture Perps de 7GVC) | solde courant rendu |
| transaction échouée | aucun mouvement |

Le rejeu historique (`investigations/2026-11-06_historical_replay/scripts/h_decode.py`) utilise désormais ce module.

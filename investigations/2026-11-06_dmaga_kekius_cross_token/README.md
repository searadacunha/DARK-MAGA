# DMAGA × Kekius Maximus : enquête croisée entre tokens

Question : les wallets qui ont profité de Dark MAGA en juillet 2024 ont-ils participé aux tokens Kekius Maximus de décembre
2024 ? La réponse suit les fonds, pas les ressemblances.

| Fichier | Contenu |
|---|---|
| `FINDINGS.md` | Constats classés CONFIRMÉ, CORROBORÉ, HYPOTHÈSE ou REJETÉ |
| `TIMELINE.md` | Chronologie UTC : chaîne, posts X et presse, séparés |
| `WALLET_OVERLAP.csv` | Correspondances entre adresses Kekius et DMAGA, avec leur classement |
| `FUNDING_GRAPH.csv` | Provenance et destination des fonds (tx, montant, heure, traçabilité) |
| `CROSSCHAIN_FLOWS.csv` | Flux entre chaînes testés |
| `UNRESOLVED.md` | Pistes ouvertes |
| `METHODOLOGY.md` | Sources, règles de calcul, limites |
| `RESEARCH_STATUS.md` | État de reprise |
| `evidence/receipts/` | Transactions Solana citées, figées |
| `evidence/social/` | Chronologie archivée du profil de Musk (CDX, captures, posts) |
| `data/` | Transferts KEKIUS Ethereum, 100 premiers acheteurs, univers DMAGA testé |
| `scripts/`, `tests/` | Collecte, calcul, autocontrôle hors ligne |

Tests : `python3 -I -m unittest discover -s investigations/2026-11-06_dmaga_kekius_cross_token/tests -v`
